How the Date Difference Calculator works

This subtracts the start date from the end date in milliseconds and converts to whole days, then expresses that span in weeks and approximate months (using an average month length of 30.44 days).

Frequently asked questions

Does this count the end date?
This calculator shows the number of full days between the two dates; add 1 if you need an inclusive count of both dates.
Can I exclude weekends for business-day counts?
Not in this simple version &mdash; a dedicated business-days calculator excludes Saturdays and Sundays.
Why are the months approximate?
Months vary from 28 to 31 days, so any days-to-months conversion uses an average month length.
